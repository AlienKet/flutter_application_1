
# Guía Rápida: Crear y Ejecutar un Proyecto de Flutter en VS Code

## 1. Crear el proyecto
* Abre **Visual Studio Code**.
* Presiona `Ctrl + Shift + P` en tu teclado.
* Escribe `Flutter: New Project` y presiona **Enter**.
* Selecciona la opción **Application**.
* Elige la carpeta de tu computadora donde guardarás el proyecto.
* Escribe un nombre para tu aplicación en **minúsculas y sin espacios** (ejemplo: `mi_primera_app`) y presiona **Enter**.

---

## 2. Encender el emulador
* En la barra lateral izquierda de VS Code, haz clic en el icono de **Mobile Device** (el icono de teléfono).
* Selecciona tu teléfono virtual de la lista (ejemplo: `Medium Phone`).
* Haz clic en el botón de **Play** o encendido para iniciarlo.

---

## 3. Ejecutar la aplicación
* Ve al **Explorador de archivos** de VS Code (primer icono del menú lateral izquierdo).
* Despliega la carpeta **`lib`**.
* Haz clic para abrir el archivo **`main.dart`**.
* Presiona la tecla **`F5`** (o ve al menú superior: `Run`).
* Espera a que termine el proceso de compilación para ver la app ejecutándose en la pantalla del emulador.

---
Flutter es el constructor visual y la estructura de la aplicación.
Flutter no es un programa que se abre aparte, sino las herramientas y código que se usa dentro de VS Code para que aparezca la aplicación en el emulador.
